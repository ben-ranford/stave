# ADR-013: Secret values are opaque handles excluded from state artifacts

- Status: Accepted
- Date: 2026-08-12
- Owner: Security owner
- Proof command: `go test ./secret ./semantic ./replay`

## Context

Plaintext secret handling would leak into snapshots, diagnostics, replays, or logs and break the security model.

## Decision

Represent secret values as opaque handles. Exclude plaintext secret content from semantic state, snapshots, results, diagnostics, and replay artifacts.

## Consequences

- Secret input requires dedicated runtime and storage handling.
- Non-interactive callers must fail closed or provide a secure source.
- Redaction becomes a hard release gate.
