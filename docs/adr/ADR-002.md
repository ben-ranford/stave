# ADR-002: Immutable semantic tree is canonical

- Status: Accepted
- Date: 2026-08-12
- Owner: Semantic owner
- Proof command: `go test ./...`

## Context

Stave needs one deterministic contract for rendering, accessibility, replay, and agent control. Mutable widget trees make identity, concurrency, and replay harder to reason about.

## Decision

Use an immutable semantic tree as the canonical representation for rendering, accessibility, tests, and agents.

## Consequences

- Snapshots and agents operate on semantic state, not rendered bytes.
- Published trees cannot be mutated by callers.
- Golden rendering is useful evidence, but not the primary truth source.
