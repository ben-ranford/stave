# ADR-016: Golden rendering supplements semantic, property, and conformance tests

- Status: Accepted
- Date: 2026-08-12
- Owner: Test owner
- Proof command: `go test ./conformance ./primitive`

## Context

Golden output can catch regressions, but it is fragile and insufficient by itself for semantic, replay, accessibility, or security guarantees.

## Decision

Use golden rendering as supplementary evidence only. Semantic assertions, property tests, adversarial fixtures, and conformance suites are the primary verification surfaces.

## Consequences

- Render snapshots do not become the only oracle.
- Contract tests must exist at semantic, action, protocol, and primitive layers.
- Visual regressions can be caught without weakening deterministic semantic guarantees.
