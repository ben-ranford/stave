# ADR-001: Stave-native core; external TUI frameworks are adapters

- Status: Accepted
- Date: 2026-08-12
- Owner: Architecture owner
- Proof command: `make adapters`

## Context

Charm, tcell, and other terminal libraries can accelerate delivery, but they carry runtime and compatibility churn that should not define Stave core semantics.

## Decision

Keep the Stave semantic model, action registry, replay, capabilities, themes, layout, and protocol Stave-native. Frameworks such as Bubble Tea or Lip Gloss are adapter concerns only.

## Consequences

- Core contracts remain independent of framework releases.
- Optional integrations live behind nested modules.
- Adapter churn must not force a core breaking release.
