# ADR-004: Target references include NodeID, generation, and observed revision

- Status: Accepted
- Date: 2026-08-12
- Owner: Protocol owner
- Proof command: `go test ./protocol ./runtime/agent`

## Context

Stable identity alone is not enough when nodes can be replaced or snapshots become stale between observation and action.

## Decision

Every action target reference must include `nodeId`, `generation`, and `observedRevision`.

## Consequences

- Stale snapshots fail closed.
- Node replacement does not silently remap actions.
- Human and agent dispatch paths share the same stale-target protections.
