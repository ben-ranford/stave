# ADR-012: Machine stdout carries protocol and output only; diagnostics use stderr or observers

- Status: Accepted
- Date: 2026-08-12
- Owner: Runtime owner
- Proof command: `go test ./runtime/agent ./protocol`

## Context

Diagnostics mixed into machine stdout corrupt protocol clients and undermine deterministic automation.

## Decision

Reserve stdout for protocol and machine-readable output. Route diagnostics through stderr or structured observers.

## Consequences

- Machine clients can trust stdout framing.
- Diagnostics remain available without polluting snapshots or actions.
- Secret redaction must still apply to observer output.
