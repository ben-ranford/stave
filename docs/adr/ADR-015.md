# ADR-015: Root and optional adapters are separate Go modules

- Status: Accepted
- Date: 2026-08-12
- Owner: Build owner
- Proof command: `make adapters`

## Context

Optional adapters should not drag their dependency trees, release cadences, or toolchain churn into the root module.

## Decision

Keep the root module and each optional adapter as separate Go modules.

## Consequences

- Consumers can import core without adapter dependencies.
- Adapter releases can move independently.
- Import-boundary verification becomes a required release check.
