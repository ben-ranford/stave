# ADR-008: Capabilities are negotiated immutable manifests with safe degradation

- Status: Accepted
- Date: 2026-08-12
- Owner: Capability owner
- Proof command: `go test ./...`

## Context

TTY, colour, Unicode, motion, viewport, and input support vary widely. Silent guessing makes behavior non-deterministic and unsafe.

## Decision

Capability negotiation produces immutable manifests, and degradation paths are explicit rather than inferred mid-session.

## Consequences

- Narrow, ASCII, no-colour, reduced-motion, and non-TTY behavior are first-class.
- Machine clients can reason about fidelity and fallback safely.
- Capability mismatches fail with structured errors instead of best-effort guessing.
