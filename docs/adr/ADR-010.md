# ADR-010: Human and agent commands resolve to the same typed action registry

- Status: Accepted
- Date: 2026-08-12
- Owner: Action owner
- Proof command: `go test ./action ./keymap ./conformance`

## Context

Separate human and machine action models drift over time and break accessibility and automation parity.

## Decision

Resolve human and agent commands through the same typed action registry, validation, target checks, capability checks, and confirmation policy.

## Consequences

- Keyboard parity is enforceable.
- Stale-target and authorization rules are consistent.
- A rendered command label can never bypass schema validation.
