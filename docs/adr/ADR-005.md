# ADR-005: Reducers and views are pure; all I/O is an effect

- Status: Accepted
- Date: 2026-08-12
- Owner: Session owner
- Proof command: `go test ./effect ./session`

## Context

Hidden I/O breaks determinism, headless testing, and replay.

## Decision

Reducers and view functions remain pure relative to their inputs. All filesystem, process, network, or clock interaction crosses an explicit effect boundary.

## Consequences

- Replay can reproduce state transitions from recorded inputs and effect outcomes.
- Runtime cancellation and timeout policy can be centralized.
- Application side effects stay auditable and testable.
