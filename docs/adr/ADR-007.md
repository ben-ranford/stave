# ADR-007: Rendering flows from semantic tree to layout plan to cell surface to sink

- Status: Accepted
- Date: 2026-08-12
- Owner: Render owner
- Proof command: `go test ./render/... ./surface`

## Context

Direct rendering from domain or adapter state would couple layout, styling, and output sinks too tightly.

## Decision

Use the staged rendering pipeline `semantic tree -> layout plan -> cell surface -> sink`.

## Consequences

- Terminal and headless outputs can share semantics while differing at the sink.
- Layout and surface logic become independently testable.
- Sanitization remains a final-sink responsibility.
