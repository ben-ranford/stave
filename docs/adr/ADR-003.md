# ADR-003: Stable IDs derive from application-owned logical keys

- Status: Accepted
- Date: 2026-08-12
- Owner: Semantic owner
- Proof command: `go test ./semantic`

## Context

Agents, replay, and accessibility require durable identifiers that survive sort, filter, and layout changes. Labels and coordinates are insufficient.

## Decision

Derive stable node identifiers from application-owned logical keys using a versioned algorithm.

## Consequences

- Node identity changes are compatibility events.
- Applications must supply stable logical key inputs for durable nodes.
- Duplicate or malformed logical keys fail validation instead of remapping heuristically.
