# ADR-011: JSON-RPC 2.0 over JSONL stdio is the v1 agent transport

- Status: Accepted
- Date: 2026-08-12
- Owner: Protocol owner
- Proof command: `go test ./protocol ./runtime/agent`

## Context

The v1 agent surface needs a typed transport that works well for local automation, replay, and bounded machine output.

## Decision

Use JSON-RPC 2.0 messages over JSONL stdio as the v1 agent transport.

## Consequences

- Machine stdout must stay protocol-clean.
- Handshake, capabilities, snapshots, and actions are versioned protocol artifacts.
- Lower-fidelity fallbacks must be explicitly negotiated.
