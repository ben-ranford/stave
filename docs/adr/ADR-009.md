# ADR-009: Themes use semantic roles and are supplied by applications

- Status: Accepted
- Date: 2026-08-12
- Owner: Theme owner
- Proof command: `go test ./...`

## Context

Stave must support multiple branded applications without inheriting a framework house style or Lopper-specific token names.

## Decision

Themes resolve semantic roles and are supplied by applications or brand packs. Core primitives accept semantic roles, not raw colour literals or Lopper semantics.

## Consequences

- Two applications can render the same primitive tree differently without changing meaning.
- Brand evolution stays application-owned.
- Missing-token validation becomes a release gate.
