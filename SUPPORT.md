# Support

This repository accepts public issue reports through its tracked forms. Use them for reproducible bugs and scoped feature requests.

## Before opening an issue

- Run `make fast` for local changes and `make verify` for push-ready validation.
- Check `CHANGELOG.md` and the current branch or tag to confirm the behavior is still current.
- Include the exact Go version, commit or tag, and focused reproduction steps.

## Request routing

- Bugs: use the bug issue form with validation evidence.
- Features and release-shape requests: use the feature issue form with API and changelog impact.
- Security concerns: follow `SECURITY.md` and report privately.

The repository owner decides support priority based on release risk, compatibility impact, and current roadmap commitments.
